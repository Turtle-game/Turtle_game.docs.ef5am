# ElytraF5 Settings API documentation

Open [index.html](index.html) for the themed landing page. The documentation is available in French and English:

- French: [quick start](fr/index.html), [API reference](fr/reference.html), [integration](fr/integration.html), [complete examples](fr/examples.html), [FAQ and lifecycle](fr/faq.html).
- English: [quick start](en/index.html), [API reference](en/reference.html), [integration](en/integration.html), [complete examples](en/examples.html), [FAQ and lifecycle](en/faq.html).

The guides cover API contracts, identifier validation, category registration, config persistence, translated strings, custom icons, optional dependencies, action screens, Java interop, examples, limitations and troubleshooting.

The API is client-only. Check the current source signatures in `src/client/kotlin/net/turtle/ef5am/api/client/settings/ElytraF5SettingsApi.kt`.
